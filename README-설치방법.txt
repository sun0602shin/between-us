우리 사이 (Between Us) 설치 방법

추천 GitHub 저장소 이름: between-us
예상 웹앱 주소: https://<사용자이름>.github.io/between-us/

1) GitHub에서 새 저장소 'between-us'를 만듭니다.
   GitHub Pages 무료 배포를 위해 저장소를 Public으로 설정하세요.
   ※ 저장소에는 앱 소스와 아이콘만 올리고 감정/일기/백업 JSON 파일은 절대 올리지 마세요.
2) 이 폴더에 들어 있는 파일 7개를 저장소 최상위(루트)에 업로드합니다.
   index.html, app.js, style.css, manifest.webmanifest, sw.js,
   icon-192.png, icon-512.png, icon-180.png (총 8개)
3) Settings → Pages → Build and deployment → Deploy from a branch
   Branch: main, Folder: / (root) → Save.
4) https://<사용자이름>.github.io/between-us/ 에 접속합니다.
5) 엄마·딸 각자 iPhone Safari에서 열고 공유 버튼 → 홈 화면에 추가합니다.
6) 각자 처음 실행할 때 엄마/딸 역할을 선택합니다.
7) 기록은 각자의 iPhone에 저장됩니다.

공유·백업
- iCloud Drive의 '우리 사이' 폴더를 만들고 상대방 Apple 계정에 공유합니다.
- 각 기기 더보기 → 내 공유 기록 내보내기 → 파일 앱 공유 폴더에 저장.
- 상대방은 더보기 → 상대방 기록 가져오기 → JSON 파일 선택.
- 두 사람이 모두 내보내고 상대방 파일을 가져오면 서로의 최근 기록을 볼 수 있습니다.
- 개인 비공개 기록이 포함된 '전체 개인 백업'은 공유 폴더에 넣지 마세요.
- 내보내기 완료 표시만으로 iCloud 업로드 완료가 보장되는 것은 아닙니다.

주의
- GitHub Pages의 공개 저장소에는 실제 가족 기록을 업로드하면 안 됩니다.
- 로컬 데이터를 삭제하거나 아이폰을 교체하면 백업하지 않은 기록을 잃을 수 있습니다.
- 권한 구분은 화면용 역할 선택이며 비밀번호 기반 본인 인증은 아닙니다.
- 동시 수정 병합은 수정 시각 기준으로 처리하므로 중요한 기록은 따로 백업하세요.
- 아이콘 변경 뒤 이전 아이콘이 보일 경우 홈 화면 아이콘을 삭제하고 다시 추가해 보세요.
